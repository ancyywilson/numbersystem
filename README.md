# Number System Converter

A simple and user-friendly Number System Converter Tool that allows users to input a number in one system (Binary, Decimal, Octal, or Hexadecimal) and instantly get the equivalent values in the other number systems.

This project is designed to help students and beginners understand number system conversions in an easy and interactive way.

## 🚀 Features

✅ Convert Binary → Decimal, Octal, Hexadecimal

✅ Convert Decimal → Binary, Octal, Hexadecimal

✅ Convert Octal → Binary, Decimal, Hexadecimal

✅ Convert Hexadecimal → Binary, Decimal, Octal

✅ Simple and clean user interface

✅ Instant conversion results

✅ Beginner-friendly project

## 🎯 Learning Objectives

Number system concepts

Base conversions

JavaScript number methods
